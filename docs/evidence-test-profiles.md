# ตัวอย่างข้อมูลสำหรับทดสอบเดโม

สองชุดนี้ตั้งจากเกณฑ์ในงานวิจัย ไม่ได้ลอกแถวจากไฟล์ฝึก อาชีพต้องกรอกเพราะฟอร์มบังคับ แต่ไม่มีในเกณฑ์ที่อ้าง ส่วนสูงใช้ 170 ซม. แล้วเลือกน้ำหนักให้ได้หมวด BMI ตามเกณฑ์

เดโมจำแนกเป็น `None`, `Insomnia` หรือ `Sleep Apnea` ผลด้านล่างมาจากการส่งชุดนี้เข้าโมเดลของโปรเจกต์แล้วดูคลาสที่ความน่าจะเป็นสูงสุด

## ตัวอย่าง ก: เครื่องหมายความเสี่ยงภาวะหยุดหายใจขณะหลับ

| ช่องในฟอร์ม | ค่าที่กรอก |
| --- | --- |
| เพศ | Male |
| อายุ | 55 |
| อาชีพ | Nurse |
| น้ำหนัก | 102 กก. |
| ส่วนสูง | 170 ซม. |
| BMI ที่ระบบคำนวณ | 35.3 หมวดอ้วน |
| ระยะเวลานอน | 7.0 ชั่วโมง |
| คุณภาพการนอน | 7 |
| กิจกรรมทางกาย | 60 นาทีต่อวัน |
| ความเครียด | 5 |
| จำนวนก้าว | 6,000 |
| ชีพจร | 72 |

ตัวเลขที่อ้างอิงได้มีสามจุดในฟอร์มลึกปัจจุบัน: เพศชาย อายุมากกว่า 50 ปี และ BMI มากกว่า 35 (อ้วนระดับ 2 ตามองค์การอนามัยโลก) โมเดลเวอร์ชัน 2 **ไม่ใช้ความดัน** เพราะไม่ใช่ค่าที่สมาร์ทวอทช์ทั่วไปมี

สี่ข้อนี้เป็นส่วนหนึ่งของแบบคัดกรอง STOP-Bang คะแนน 0–2 ถูกจัดเป็นความเสี่ยงต่ำต่อภาวะหยุดหายใจขณะหลับระดับปานกลางถึงรุนแรง และคะแนน 5–8 เป็นความเสี่ยงสูง คะแนน 3–4 ต้องใช้ข้อมูลเพิ่ม ฟอร์มลึกไม่มีช่องกรน / มีคนเห็นหยุดหายใจ (อยู่ที่ pre-screen) และไม่มีเส้นรอบคอ จึงให้ครบแปดข้อของ STOP-Bang ไม่ได้

ระยะเวลานอนตั้งที่ 7 ชั่วโมงตามคำแนะนำสำหรับผู้ใหญ่ เพื่อไม่ให้ตัวอย่างนี้ปนกับปัญหานอนสั้น

ผลคลาส/ความน่าจะเป็นอาจเปลี่ยนหลังฝึกโมเดลใหม่โดยไม่มี BP — รันเดโมหรือ `python model.py` เพื่อยืนยันค่าล่าสุด

## ตัวอย่าง ข: เครื่องหมายความเสี่ยงนอนไม่หลับ

| ช่องในฟอร์ม | ค่าที่กรอก |
| --- | --- |
| เพศ | Female |
| อายุ | 47 |
| อาชีพ | Accountant |
| น้ำหนัก | 65 กก. |
| ส่วนสูง | 170 ซม. |
| BMI ที่ระบบคำนวณ | 22.5 หมวดปกติ |
| ระยะเวลานอน | 5.5 ชั่วโมง |
| คุณภาพการนอน | 4 |
| กิจกรรมทางกาย | 50 นาทีต่อวัน |
| ความเครียด | 8 |
| จำนวนก้าว | 7,000 |
| ชีพจร | 70 |

5.5 ชั่วโมงต่ำกว่า 7 ชั่วโมงที่แนะนำสำหรับผู้ใหญ่ และอยู่ในช่วง 6 ชั่วโมงหรือน้อยกว่าที่คณะผู้จัดทำฉันทามติเห็นว่าไม่เหมาะสมต่อสุขภาพ การศึกษาติดตามผู้ใหญ่ 2,316 คนที่ตอนเริ่มต้นไม่มีประวัติ insomnia พบว่าเหตุการณ์เครียดสัมพันธ์กับโอกาสเกิด insomnia ในหนึ่งปีข้างหน้า อัตราส่วน odds 1.13 ต่อหนึ่งเหตุการณ์ คนที่การนอนไวต่อความเครียดสูงมีอัตราส่วน odds 1.78 ต่อหนึ่งส่วนเบี่ยงเบนมาตรฐาน

คะแนนความเครียด 8 เป็นค่าสูงของฟอร์มนี้ (หรือ map จากคะแนน stress ของนาฬิกา) ไม่ใช่คะแนนจากแบบวัดในงานวิจัยนั้น BMI ตั้งในช่วงปกติ เพื่อไม่ให้ปนกับเครื่องหมายของภาวะหยุดหายใจขณะหลับ

ผลคลาส/ความน่าจะเป็นอาจเปลี่ยนหลังตัด BP ออก — รันเดโมหรือ `python model.py` เพื่อยืนยันค่าล่าสุด ระยะ 5.5 ชั่วโมงต่ำกว่าค่าต่ำสุดในตารางฝึกซึ่งอยู่ที่ 5.8 หน้าผลจึงควรขึ้นหมายเหตุว่าค่านี้อยู่นอกช่วงข้อมูลฝึก

## ตัวอย่างคัดกรองขั้น Pre-screen (กฎปัจจุบัน)

ใช้กับหน้า `#screen` ก่อนเข้าฟอร์มลึก ระบบปลดล็อก `#assess` หลังทำ triage ครบ  
ผล `Insomnia` / `Sleep Apnea` แนะนำให้ไปลึกต่อ ผล `None` เลือกไปต่อได้ (ไม่บังคับ)  
คะแนน STOP-Bang / ISI-inspired แสดงคู่ขนาน แต่ไม่ได้แทนกฎ triage

| เคส | คำตอบใช่ | ผลที่คาดหวัง |
| --- | --- | --- |
| อ่อนเกินเกณฑ์ | ข้อ 2 กรน อย่างเดียว | `None` พร้อมปุ่มไปลึกแบบเลือกได้ |
| อยู่คนเดียว | ข้อ 2 และ 3 เป็น ไม่ทราบ | `None` (unknown ไม่นับเป็น hit) |
| อยู่คนเดียว + proxy | ข้อ 2–3 ไม่ทราบ + ข้อ 4 และ 8 ใช่ | ติด Sleep Apnea จากอาการที่สังเกตเอง |
| Insomnia ผ่านเกณฑ์ | ข้อ 1 และ 6 | ติด Insomnia → ไปฟอร์มลึกได้ |
| Apnea ผ่านเกณฑ์ | ข้อ 2 และ 5 | ติด Sleep Apnea → ไปฟอร์มลึกได้ |
| Apnea red-flag | ข้อ 3 หยุดหายใจขณะหลับ | ติด Sleep Apnea แม้มีแค่ 1 ข้อแดง |
| ลู่ทางเดโมหลัก | ข้อ 3 + ใช้โปรไฟล์ ก ในฟอร์มลึก | โชว์ pre-screen vs model, hybrid, standards, logs/trust |

ตรวจกฎอัตโนมัติ:

```powershell
python scripts\check_triage.py
```
