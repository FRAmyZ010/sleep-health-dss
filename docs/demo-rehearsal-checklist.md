## สคริปต์เดโม 2–3 นาที (เฟรม)

1. **ล็อกประเมินลึก**  
   กดเมนู Deep assess โดยยังไม่คัดกรอง → ต้องขึ้นข้อความล็อก แล้วเด้งไป Screening

2. **เกณฑ์เข้ม + ทางเลือก None**  
   ที่ `#screen` ตอบใช่แค่ “กรน” ที่เหลือไม่ใช่ → กดคัดแยก → ต้องได้ `None`  
   ต้องมีปุ่มกลับหน้าแรก และปุ่มไปประเมินเชิงลึกต่อได้  
   (ทางเลือก) ข้อ 2–3 เลือก “ไม่ทราบ / อยู่คนเดียว” + ข้อ 4 และ 8 ใช่ → ต้องติด Sleep Apnea

3. **Red-flag + คะแนนมาตรฐาน**  
   ล้างคำตอบ แล้วใช่ข้อหยุดหายใจขณะหลับ (ข้อ 3) → ต้องติด Sleep Apnea  
   ชี้แผง STOP-Bang / ISI-inspired ว่าเป็นคะแนนคู่ขนาน ไม่ได้ปลดล็อกแทนกฎ triage

4. **ประเมินลึก + ผล**  
   ใช้โปรไฟล์ ก จาก `docs/evidence-test-profiles.md`  
   ดูหน้าผล: pre-screen vs model, hybrid score, confidence band, คำแนะนำ, คะแนนมาตรฐานที่เติม BMI/อายุ/เพศ

5. **Logs + Trust**  
   เปิด `#logs` → ต้องมีแถว anonymous ใหม่ และปุ่ม Download CSV ใช้ได้  
   เปิด `#trust` → ชี้ proxy GT (Kaggle CV) และตารางโปรไฟล์อ้างอิง

6. **สำรวจ (ถ้าเหลือเวลา 20 วินาที)**  
   `#eda` ชี้ 1 กราฟ + แถบ CV

## เคสสำรองถ้าต้องโชว์ conflict

- Pre-screen: red-flag apnea  
- ฟอร์มลึก: โปรไฟล์ที่โมเดลมักออกใกล้ `None` / คนละกลุ่ม  
- ชี้ banner conflict ว่าบังคับพบแพทย์
