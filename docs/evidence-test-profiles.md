# ตัวอย่างข้อมูลสำหรับทดสอบเดโม

สองชุดนี้ตั้งจากเกณฑ์ในงานวิจัย ไม่ได้ลอกแถวจากไฟล์ฝึก อาชีพต้องกรอกเพราะฟอร์มบังคับ แต่ไม่มีในเกณฑ์ที่อ้าง ส่วนสูงใช้ 170 ซม. แล้วเลือกน้ำหนักให้ได้หมวด BMI ตามเกณฑ์

เดโมจำแนกเป็น `None`, `Insomnia` หรือ `Sleep Apnea` ผลด้านล่างมาจากการส่งชุดนี้เข้าโมเดลของโปรเจกต์แล้วดูคลาสที่ความน่าจะเป็นสูงสุด

## ตัวอย่าง ก: เครื่องหมายความเสี่ยงภาวะหยุดหายใจขณะหลับ

| ช่องในฟอร์ม | ค่าที่กรอก |
| --- | --- |
| เพศ | Male |
| อายุ | 55 |
| อาชีพ | Nurse |
| น้ำหนัก | 102 กก. |
| ส่วนสูง | 170 ซม. |
| BMI ที่ระบบคำนวณ | 35.3 หมวดอ้วน |
| ระยะเวลานอน | 7.0 ชั่วโมง |
| คุณภาพการนอน | 7 |
| กิจกรรมทางกาย | 60 นาทีต่อวัน |
| ความเครียด | 5 |
| จำนวนก้าว | 6,000 |
| ความดัน | 140/90 |
| ชีพจร | 72 |

ตัวเลขที่อ้างอิงได้มีสี่จุด: เพศชาย อายุมากกว่า 50 ปี BMI มากกว่า 35 และความดัน 140/90 ซึ่งถึงเกณฑ์ความดันโลหิตสูงระยะที่ 2 ของ ACC/AHA ปี 2017 BMI 35.3 อยู่ในช่วงอ้วนระดับ 2 ตามองค์การอนามัยโลก

สี่ข้อนี้เป็นส่วนหนึ่งของแบบคัดกรอง STOP-Bang คะแนน 0–2 ถูกจัดเป็นความเสี่ยงต่ำต่อภาวะหยุดหายใจขณะหลับระดับปานกลางถึงรุนแรง และคะแนน 5–8 เป็นความเสี่ยงสูง คะแนน 3–4 ต้องใช้ข้อมูลเพิ่ม ฟอร์มนี้ไม่มีช่องกรน ง่วงกลางวัน มีคนเห็นหยุดหายใจ และเส้นรอบคอ จึงให้ครบแปดข้อของ STOP-Bang ไม่ได้

ระยะเวลานอนตั้งที่ 7 ชั่วโมงตามคำแนะนำสำหรับผู้ใหญ่ เพื่อไม่ให้ตัวอย่างนี้ปนกับปัญหานอนสั้น

ผลในเดโมเมื่อใช้อาชีพ Nurse คือ `Sleep Apnea` ความน่าจะเป็น 0.497 อีกสิบอาชีพในเมนูได้ `Insomnia` ความน่าจะเป็นประมาณ 0.44–0.50

## ตัวอย่าง ข: เครื่องหมายความเสี่ยงนอนไม่หลับ

| ช่องในฟอร์ม | ค่าที่กรอก |
| --- | --- |
| เพศ | Female |
| อายุ | 47 |
| อาชีพ | Accountant |
| น้ำหนัก | 65 กก. |
| ส่วนสูง | 170 ซม. |
| BMI ที่ระบบคำนวณ | 22.5 หมวดปกติ |
| ระยะเวลานอน | 5.5 ชั่วโมง |
| คุณภาพการนอน | 4 |
| กิจกรรมทางกาย | 50 นาทีต่อวัน |
| ความเครียด | 8 |
| จำนวนก้าว | 7,000 |
| ความดัน | 118/76 |
| ชีพจร | 70 |

5.5 ชั่วโมงต่ำกว่า 7 ชั่วโมงที่แนะนำสำหรับผู้ใหญ่ และอยู่ในช่วง 6 ชั่วโมงหรือน้อยกว่าที่คณะผู้จัดทำฉันทามติเห็นว่าไม่เหมาะสมต่อสุขภาพ การศึกษาติดตามผู้ใหญ่ 2,316 คนที่ตอนเริ่มต้นไม่มีประวัติ insomnia พบว่าเหตุการณ์เครียดสัมพันธ์กับโอกาสเกิด insomnia ในหนึ่งปีข้างหน้า อัตราส่วน odds 1.13 ต่อหนึ่งเหตุการณ์ คนที่การนอนไวต่อความเครียดสูงมีอัตราส่วน odds 1.78 ต่อหนึ่งส่วนเบี่ยงเบนมาตรฐาน

คะแนนความเครียด 8 เป็นค่าสูงของฟอร์มนี้ ไม่ใช่คะแนนจากแบบวัดในงานวิจัยนั้น ความดันและ BMI ตั้งในช่วงปกติ เพื่อไม่ให้ปนกับเครื่องหมายของภาวะหยุดหายใจขณะหลับ

ผลในเดโมเป็น `None` ทั้ง 11 อาชีพ อาชีพ Accountant ได้ความน่าจะเป็น 0.723 ระยะ 5.5 ชั่วโมงต่ำกว่าค่าต่ำสุดในตารางฝึกซึ่งอยู่ที่ 5.8 หน้าผลจึงควรขึ้นหมายเหตุว่าค่านี้อยู่นอกช่วงข้อมูลฝึก
